# 🚀 CODIGO5

Um projeto de **desenvolvimento web para uma loja**, criado com foco em uma apresentação moderna de produtos, navegação simples e boa experiência para o usuário.

## 🛍️ Sobre o projeto

O **CODIGO5** foi desenvolvido para apresentar produtos de forma organizada e atrativa, utilizando tecnologias Front-end.

O projeto também foi pensado para funcionar em diferentes dispositivos, proporcionando uma experiência responsiva para os usuários.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Design Responsivo

## ✨ Funcionalidades

* 🏠 Página inicial
* 🛍️ Apresentação de produtos
* 🖼️ Imagens dos produtos
* 📱 Layout responsivo
* 🎨 Interface moderna
* 📲 Área de contato
* 🔗 Integração com redes sociais

## 📱 Responsividade

O projeto foi desenvolvido para funcionar em:

* 💻 Computadores
* 📱 Smartphones
* 📲 Tablets

## 🎯 Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos de **desenvolvimento Front-end**, trabalhando com estrutura de páginas, estilização, responsividade e interações com JavaScript.
